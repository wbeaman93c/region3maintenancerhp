# Tennessee Rural Service Patrol — Region 4 Update

- Region 4 truck range is **8400–8409** (10 trucks).
- Region 4 Mileage / Oil Changes page records truck, date, current odometer mileage, whether an oil change was completed at that mileage, and other reported issues or maintenance needs.
- No mechanic name, oil type, oil quantity, or filter information is collected.
- Oil change interval is 5,000 miles from the last recorded oil-change mileage, with a due-soon warning in the final 500 miles.
- **Region 4 Records** is a separate navigation tab with saved entries and a truck filter.
- Region 4 data is stored separately from Region 3 PM inspection reports.
- Existing persistent `/app/data` storage setup and Region 3 data are retained.
